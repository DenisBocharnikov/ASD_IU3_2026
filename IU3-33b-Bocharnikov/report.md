# Лабораторная работа №1 — решения на 15 баллов

Выбрано 15 задач. Ввод: сначала `n`, затем `n` элементов массива. Для задач 2, 3, 4, 10 дополнительное число вводится после массива. Для задачи 31 второй массив вводится после первого.

| Задача | Название | Время | Дополнительная память |
|---|---|---|---|
| 1 | Максимум и минимум | O(n) | O(n) для хранения входного массива |
| 2 | Индекс первого вхождения | O(n) | O(n) для хранения входного массива |
| 3 | Подсчёт вхождений | O(n) | O(n) для хранения входного массива |
| 4 | Все индексы элемента | O(n) | O(n) для хранения входного массива |
| 5 | Сумма элементов на чётных позициях | O(n) | O(n) для хранения входного массива |
| 6 | Элементы больше среднего | O(n) | O(n) для хранения входного массива |
| 7 | Второй максимум | O(n) | O(n) для хранения входного массива |
| 8 | Фильтрация по знаку | O(n) | O(n) для хранения входного массива |
| 9 | Проверка отсортированности | O(n) | O(n) для хранения входного массива |
| 10 | Поиск последнего элемента, кратного k | O(n) | O(n) для хранения входного массива |
| 25 | Сумма элементов | O(n) | O(n) для хранения входного массива |
| 26 | Произведение элементов по модулю 1000000007 | O(n) | O(n) для хранения входного массива |
| 27 | Сумма квадратов | O(n) | O(n) для хранения входного массива |
| 31 | Скалярное произведение | O(n) | O(n) для хранения входного массива |
| 36 | Бегущая сумма | O(n) | O(n) для хранения входного массива |

Каждый алгоритм обходит массив один или два раза. Поэтому время O(n), а память O(n) из-за хранения входного массива. Задачи 4, 8 и 36 дополнительно хранят результат длиной до n. Остальные используют O(1) памяти сверх входного массива.

## Идеи решений

- **1:** Обновляем минимум и максимум при обходе.
- **2:** Останавливаемся на первом совпадении.
- **3:** Считаем совпадения.
- **4:** Собираем все индексы совпадений.
- **5:** Суммируем индексы 0, 2, 4 и т. д.
- **6:** Считаем сумму, затем сравниваем a[i] * n с суммой, избегая округления среднего.
- **7:** Храним два наибольших значения; все элементы различны.
- **8:** Распределяем положительные и отрицательные числа, пропуская нули.
- **9:** Проверяем соседние элементы на нарушение неубывания.
- **10:** Запоминаем индекс каждого подходящего элемента; остаётся последний.
- **25:** Накапливаем сумму в long.
- **26:** После каждого умножения берём остаток, отрицательные числа нормализуем.
- **27:** Возводим каждый элемент в квадрат в типе long.
- **31:** Суммируем попарные произведения двух массивов.
- **36:** После каждого элемента выводим накопленную сумму.

## Ручные проверки

- Задача 1: `4 8 -2 5 1` → `-2 8`.
- Задача 2: `4 2 7 2 9 2` → `0`.
- Задача 6: `4 1 2 3 6` → `1`.
- Задача 7: `4 -5 -1 -3 -2` → `-2`.
- Задача 8: `5 -1 0 3 -2 4` → две строки: `3 4` и `-1 -2`.
- Задача 9: `4 1 1 2 3` → `YES`.
- Задача 26: `3 -2 3 4` → `999999983`.
- Задача 31: `3 1 2 3 4 5 6` → `32`.
- Задача 36: `4 1 -2 3 4` → `1 -1 2 6`.

## Запуск
